## Calculadora - Version1
Essa versão da calculadora em C irá funcionar lendo um arquivo chamado "number.txt", no qual existirão 3 linhas :
  - A primeira linha, a qual contém um valor;
  - A segunda linha que tem outro valor;
  - A terceira linha, que possui uma palavra chave ou caractere que indica uma operação.
  - Qualquer outra linha será ignorada.

Ao rodar o programa, o resultado da operação estará escrito no arquivo "calc.txt". Ambos "calc.txt" e "number.txt" estão como arquivos vazios dentro de Calculadora/Version1/program_files.

---
This version of the calculator program in C will work by reading a file called "number.txt", in which there will be 3 lines :
  - The first line, which will have a value;
  - The second line, which will have another value;
  - The third line, which will have a keyword or character that indicates an operation;
  - Any other lines will be ignored.

After running this program, the output will be printed in a file called "calc.txt". "calc.txt" and "number.txt" will both be enpty file located in Calculadora/Version1/program_files.
