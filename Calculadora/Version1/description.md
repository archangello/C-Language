## Calculadora - Version1
Essa versão da calculadora em C funciona diretamente no terminal, no qual, após a compilação e execução do programa, será exibido :
  - Um prompt para o usuário digitar um número;
  - Um prompt para o usuário digitar um caractere(opções entre parenteses);
  - Um ultimo prompt para o usuário digitar outro número;

Depois disso, o programa irá exibir, ainda no terminal :
  - O primeiro número;
  - O segundo número;
  - O símbolo da operação executada;
  - O resultado da operação;

Esse caso só aparece se o operador for válido. Se não, o programa exibe uma mensagem de erro e reinicia.

---
Thsi version of the calculator program in C works directly in the terminal, in which, after the compiling and running of the program, will show :
  - A prompt for the user to input a number;
  - A prompt for the user to input a operator (option in parentheses);
  - A final prompt for the user to input another number;

After that, the program will show, still in the terminal :
  - The first number;
  - The second number;
  - The simbol of the executed operation;
  - The result of the operation;

This case only appears if the inputed operator is valid. If not, the program prints an error message and restarts.
